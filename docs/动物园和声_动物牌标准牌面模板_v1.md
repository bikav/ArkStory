# 《动物园和声》动物牌标准牌面模板 v1

本文档默认按 `TapTap Android 首发` 口径编写。  
由于牌面模板与图案编码本身不依赖平台，本文件可直接复用到其他平台版本。

## 1. 文档目的

本文件用于将《动物园和声》首发 32 张动物牌，从“自然语言描述图案”升级为“可直接进入策划配置与程序数据结构的标准牌面格式”。

本文档主要解决两个问题：

1. 为所有动物牌建立统一字段模板
2. 为所有图案要求建立统一表示法

## 2. 标准牌面字段模板

每张动物牌统一使用以下字段：

- `ID`：卡牌唯一编号
- `名称`：卡牌名称
- `颜色`：白 / 蓝 / 金 / 红
- `成本`：白 1 / 蓝 2 / 金 3 / 红 4
- `方块槽位`：默认 3
- `分值序列`：统一为 4 档，首档固定为 0
- `落点坐标`：动物方块放置位置
- `落点类型`：落点格所需的地形类型
- `图案编码`：按统一语法记录整张牌的图案
- `图案说明`：面向策划和美术的可读描述
- `标签`：用于构筑与平衡分析
- `技能字段`：MVP 阶段保留，不生效
- `平衡备注`：说明该牌的环境定位

## 3. 统一图案表示法

## 3.1 坐标系统

采用六边形棋盘的轴坐标表示法，使用 `(q,r)` 记录每个格子的相对位置。

方向定义如下：

- `(+1,0)`：东
- `(0,+1)`：东南
- `(-1,+1)`：西南
- `(-1,0)`：西
- `(0,-1)`：西北
- `(+1,-1)`：东北

所有图案都以动物方块的落点格作为原点，即：

- 落点格固定为 `(0,0)`
- 其他格子都相对 `(0,0)` 计算

## 3.2 地形编码

为避免歧义，统一使用以下编码：

- `WT`：水域，1 层蓝色
- `BN`：棕地，1 层棕色
- `YL`：田野，1 层黄色
- `M1`：1 层山，1 枚灰色
- `M2`：2 层山，2 枚灰色堆叠
- `M3`：3 层山，3 枚灰色堆叠
- `T1`：1 层树，1 枚绿色
- `T2`：2 层树，绿色位于 1 层棕色之上
- `T3`：3 层树，绿色位于 2 层棕色之上
- `H`：建筑，红色位于合法底座之上

说明：

- `H` 当前不区分底座颜色，默认表示任意合法建筑
- 如后续需要区分，可扩展为 `HB` / `HG` / `HR`

## 3.3 图案语法

统一语法如下：

`{ (q,r):TYPE, (q,r):TYPE, ... }`

其中：

- `(q,r)` 为格子坐标
- `TYPE` 为该格子的地形编码
- 落点格始终为 `(0,0)`，不再额外加星号
- 动物方块放置要求由 `落点类型` 单独记录

示例：

`{ (0,0):T1, (1,0):BN }`

含义：

- 落点格是 `(0,0)`，类型为 `T1`
- 右侧相邻格 `(1,0)` 必须是 `BN`

## 3.4 分值序列说明

所有动物牌的分值序列都以 `0` 开头，例如：

- `0/2/4/6`
- `0/3/6/9`
- `0/4/8/12`

这里的首项 `0` 表示：

- 该牌已经进入进行中区域
- 但尚未在地图上成功放置任何动物方块

如果整局都没有完成过该牌的任何一次图案，则该牌结算为 `0 分`。

## 4. 标准牌面模板示例

以下以 `W01 林间兔` 为示例：

- `ID`：W01
- `名称`：林间兔
- `颜色`：白
- `成本`：1
- `方块槽位`：3
- `分值序列`：0/2/4/6
- `落点坐标`：(0,0)
- `落点类型`：T1
- `图案编码`：`{ (0,0):T1, (1,0):BN }`
- `图案说明`：落点是一棵 1 层树，右侧相邻 1 格为棕地
- `标签`：树冠、基础
- `技能字段`：null
- `平衡备注`：白色树线起手牌，完成率高，上限低

## 6. 统一完成段数规则

首发 32 张动物牌当前统一为：

- 方块槽位 3 个
- 完成段数 3 段
- 分值序列 4 档

也就是：

1. 未完成：0 分
2. 完成 1 次：进入第 2 档分值
3. 完成 2 次：进入第 3 档分值
4. 完成 3 次：进入第 4 档分值

这样做的好处：

1. 便于 UI 统一设计
2. 便于玩家理解
3. 便于首发环境比较不同颜色动物牌的完成效率
