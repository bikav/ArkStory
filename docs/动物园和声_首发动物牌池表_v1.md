# 《动物园和声》首发动物牌池表 v1

本文档默认按 `TapTap Android 首发` 口径编写。  
由于首发牌池本身属于平台无关内容，本文件可直接复用到其他平台版本。

## 1. 文档目的

本文件用于定义《动物园和声》MVP 阶段的首发动物牌池。

目标不是一次把所有牌面细化到美术出图级，而是先建立一套可测试、可平衡、可扩充的基础牌池结构，用于：

1. 验证 `12 张牌库 + 4 选 1` 构筑是否成立
2. 验证 `24 成本上限` 下的构筑多样性
3. 验证地形分与动物牌分的比例是否健康
4. 为后续 UI、原型和数值测试提供统一底稿

## 2. 首发牌池总览

首发动物牌总数：`32 张`

按颜色分布：

- 白色：`12 张`
- 蓝色：`10 张`
- 金色：`6 张`
- 红色：`4 张`

分布目的：

1. 白色占比 37.5%，保证基础启动层足够厚
2. 蓝色作为中坚层，承担大部分方向构筑
3. 金色数量控制，避免环境过快收敛
4. 红色占比 12.5%，只作为少量高上限核心牌

## 3. 牌面字段说明

每张动物牌包含以下字段：

- `ID`：唯一编号
- `名称`：当前设计代号，可后续替换为正式命名
- `颜色`：白 / 蓝 / 金 / 红
- `成本`：白 1 / 蓝 2 / 金 3 / 红 4
- `分值`：按“最上方未覆盖分值”结算
- `图案要求`：当前为原型描述，后续再细化为正式图示
- `落点颜色`：动物方块必须放置的目标颜色
- `标签`：用于构筑和后续技能扩展
- `定位`：该牌在构筑中的作用
- `技能占位`：MVP 阶段统一不生效

关于分值字段的补充说明：

- 当前所有首发动物牌的分值序列都以 `0` 开头，例如 `0/2/4/6`、`0/4/8/12`。
- 这里的第一个 `0` 代表该牌虽然已经被玩家选入进行中区域，但尚未在地图上成功放置任何一个动物方块。
- 换句话说，它表示“未完成状态”的最终结算分，而不是“起始就送 0 分”这种额外字段。
- 只要至少成功放下 1 个动物方块，这张牌的最终得分就会进入后续分值档位。

## 4. 图案描述约定

为方便当前阶段整理，本文件先用文字描述图案要求，后续进入原型时再统一转换为标准图示。

常用描述如下：

- `相邻 2 格`：2 个相邻地形
- `直线 3 格`：连续 3 格直线
- `折线 3 格`：3 格弯折
- `簇状 4 格`：中心相连的 4 格结构
- `双层山`：2 层灰色山
- `三层山`：3 层灰色山
- `双层树`：绿色位于 1 层棕色之上
- `三层树`：绿色位于 2 层棕色之上
- `建筑`：红色位于棕 / 灰 / 红之上
- `混色`：要求图案中存在多种颜色
- `精确落点`：落点格颜色必须严格匹配

## 4.1 发牌随机性说明

- 玩家带入对局的 12 张动物牌，在开局时进行完全随机洗牌。
- 系统随后从牌库顶依次抽出 4 张，形成起始备选区。
- 不同颜色类别不会拥有不同的发牌权重。
- 因此，若玩家带入了红色牌，红色牌也可能在开局 4 张备选牌中出现；若玩家带入白色牌，白色牌也并不会被系统刻意优先发放。

## 5. 首发环境路线规划

首发 32 张牌主要围绕六条构筑路线展开：

1. 山地路线
2. 树冠路线
3. 河流路线
4. 田野路线
5. 建筑路线
6. 混栖路线

设计原则：

- 每条路线都有白牌起手
- 蓝牌开始提供方向强化
- 金牌提供中期核心收益
- 红牌只作为少量高上限终点

## 10. 标签分布检查

为了保证首发环境不会只偏向单一路线，32 张牌的标签需要尽量均衡。

首发标签覆盖：

- 山地：11 张
- 树冠：10 张
- 河流：10 张
- 田野：9 张
- 建筑：6 张
- 混栖 / 混色：8 张
- 高堆叠：8 张

说明：

- 山地、树冠、河流是首发三大主流路线
- 田野承担辅助路线与混合路线作用
- 建筑牌数量刻意偏少，作为高技巧分支

## 12. 平衡检查重点

这份首发牌池进入测试后，需要重点观察以下问题：

1. 白牌是否真的值得带够 3 张以上
2. 红牌是否出现“必带某两张”的固定答案
3. 建筑路线是否过难，导致携带率过低
4. 河流路线是否因地图自然延展而过强
5. 山树高堆叠路线是否过于吃发牌与地形运气

## 13. MVP 实施建议

进入 MVP 时，建议按以下顺序落地：

1. 先接入 32 张牌的数据结构
2. 先做无技能对局
3. 用内部测试记录每张牌的携带率、选择率、完成率、平均得分
4. 至少完成一轮白牌补强和红牌削峰
5. 再考虑开放蓝牌技能的实验环境

## 14. 后续扩展方向

首发池稳定后，可追加以下方向：

1. `建筑扩展包`
2. `高山扩展包`
3. `湿地扩展包`
4. `夜行动物扩展包`
5. `赛季主题动物包`

## 15. 结论

这套 32 张首发牌池的目标，不是让每张牌都绝对平均，而是保证：

1. 每条路线都能开局
2. 每个颜色层级都有存在意义
3. 高色牌有上限但不可滥用
4. 白牌不是税，而是真正的基础资源

只有这四点成立，构筑系统才会稳定，后续技能和赛季扩展才有空间。
